Two Robots in an Elevator — one line (109 chars) of awkward small talk a robot says to another in an elevator. The shipped line is the battery one: at 2%, asking to plug into the other robot's port for one floor — and begging it not to log the moment as a relationship.

## Run it

```sh
node main.ts
```

`main.ts` (Node 22 stdlib only) picks the winning candidate from a 3×10 duel table against the joke-demo-20261123 top 10, gates it (1–200 chars, single line, ASCII-only), and writes it to `/output/entry.txt`.
